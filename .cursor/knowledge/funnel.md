# Funil

## Principal

Tráfego pago → landing page → lead (formulário e/ou WhatsApp) → conversa → proposta → venda.

## A página responde

1. O que fazemos (crescimento digital, não só site)
2. Para quem (profissionais e empresas)
3. Como ajudamos (ecossistema)
4. Como contratar (form + WhatsApp)

Não inventar preço, cliente, depoimento ou métrica.

## Ordem das seções

Hero → Problema → Solução → Serviços → Como funciona → Primeiros projetos → Por que nós → Sobre → Planos → FAQ → Formulário → CTA final

## CTAs

- Navbar: Quero crescer
- Hero primário: Quero falar com um especialista
- Hero secundário: Conhecer serviços
- Um CTA principal por bloco

## Headline

Escolhida no hero: “Seu negócio pronto para crescer no digital.”
